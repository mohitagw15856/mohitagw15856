## 👋 Hi, I'm Mohit

I was a product manager who got tired of AI giving me a very confident intern's answer. So I started writing down what the senior colleague would say — one markdown file per task — and it became **[PM Skills](https://github.com/mohitagw15856/pm-claude-skills)**: 1166 agent skills for Claude, ChatGPT, Gemini, Cursor and Codex, in Anthropic's official plugin directory, MIT, free forever.

The rule for everything I ship: **it has to be measured, or it has to say it isn't.** Evals in the open, negative findings published, a keyword baseline every fancy router has to beat.

## 💬 Ask me about

- **Agent skills** — writing them, evaluating them, publishing them to every tool at once, and why a SKILL.md beats a prompt library
- **Typed decisions** — when a probability is the right output and a paragraph is the wrong one
- **Evals that don't lie** — blind judges, keyword baselines, and publishing the misses
- **E-ink firmware** — ESP32-C3, PlatformIO, and making a two-colour screen feel fast

## 🧭 Currently

- Building the **decision layer** for PM Skills: route, guard, gate and judge, with typed questions
- Keeping 1166 skills honest with a CI that counts, lints, audits and benchmarks on every commit
- Trying to make "PM stands for Professional" stick
